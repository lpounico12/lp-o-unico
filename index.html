Banco de Dados Online (Supabase • Lp o único dec)

Conectado ao seu projeto no Supabase. Quando você salva no painel admin, os dados vão para a tabela hub_config e aparecem para todos que entrarem no site.

SQL para criar a tabela no Supabase (SQL Editor): 
create table if not exists public.hub_config (
  id text primary key,
  data jsonb not null,
  updated_at timestamptz default now()
);
alter table public.hub_config enable row level security;
create policy "Public read hub_config" on public.hub_config for select using (true);
create policy "Public insert hub_config" on public.hub_config for insert with check (true);
create policy "Public update hub_config" on public.hub_config for update using (true);
